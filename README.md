# MKJK College — Premium React Website

Maharani Kishori Jat Kanya Mahavidyalaya, Rohtak — premium warm-gold/orange redesign.

## Stack
- React 19
- Vite 7
- React Router
- React Icons
- Montserrat

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

## Design updates
- User-provided MKJK logo is stored at `public/assets/mkjk-logo.jpeg`.
- Public pages use dedicated JSX and CSS files.
- No global.css or data.js is used for public page styling/content.
- Warm cream/yellow/orange/brown visual system is applied page-by-page.
- Header has compact centered navigation with nested academic submenus.
- Home has premium hero, auto-scrolling news/notices, principal message, programme cards, campus-life cards and contact strip.
- Footer has an auto-scrolling Latest Highlight panel.
- PageHero uses the same warm institutional visual language.
